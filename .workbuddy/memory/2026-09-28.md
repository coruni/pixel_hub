## S3 多存储桶 · 第二轮（每个桶可用**不同账号/密钥/服务商**）
- 复查发现第一轮把「同一账号多桶」当默认假设，三处硬伤，全部修复：
  1. **私有桶无法独立**：原 `aclPrivate` 是布尔继承 → 改三态 `aclMode: "" | "public" | "private"`，
     `""` 才跟随主桶。为什么必须三态：布尔表达不了「没填」。
  2. **寻址风格硬编码**：原所有桶强制 path-style（`forcePathStyle: true`）→ 加三态 `urlStyle: "" | "virtual"`，
     备用桶可单独选 virtual-host style。`pathStyle` 进 client 池签名（同一 endpoint 两种风格要两个 client）。
  3. **公开基址撞车未拦**：两个桶 publicBase 相同 → 反解按最长命中会串桶 → `runtimeConfigIssues` 加拦截。
- 逐字段继承保留：备用桶留空即继承主桶（Endpoint/Region/凭据/公开基址/可见性/寻址风格各自独立可覆写）。
- zod 枚举坑：从 preprocess 出来的字段类型是 `string`，不能直接赋给枚举字段（TS2322）→
  引入 `S3AclMode`/`S3UrlStyle` 类型 + `as` 断言，校验集合用 `Set<string>`。
- 客户端包隔离：`S3BucketsEditor.tsx` 只能 `import type` runtime-config（否则 prisma 进浏览器包）。
  新建 `src/lib/storage/bucket-limits.ts` 只导出 `S3_MAX_EXTRA_BUCKETS` 常量给客户端组件用。
- 验证方法新增两条（已写进 skill）：
  - **驱动层无网络探针**：`Module._resolveFilename` 打桩 `@/lib/db/prisma` + `@aws-sdk/client-s3`，
    直接跑 s3Driver 的 put/get/size/del 断言，零网络零 DB。
  - **客户端包泄漏扫描（带反证）**：从 `"use client"` 入口沿值导入图 BFS（`import type` 擦除、遇 `"use server"` 停），
    断言不可达 `@/lib/db/prisma`；反证：临时把 type 导入改成值导入，必须变红。
- 验证：tsc + eslint 干净；探针 47+29+18 断言全绿 + 泄漏扫描（含反证）通过；探针已清理。

## S3 多存储桶 · 第三轮（容量上限 + 上传前预检）
- 起因：用户问「桶满了会自动切换？免费空间用完怎么办」。**关键事实：S3 协议没有容量查询 API**，
  应用无法主动知道桶剩多少；原有实现只能靠「写入抛错」触发切换，覆盖不到下面这一种：
  免费额度用完但**绑了卡**时服务商照写照计费、**不报错也不切**。这是唯一必须靠应用层算量的缺口。
- 方案（用户拍板）：每桶配 `s3MaxGb` / `entry.maxGb`（**GB 字符串**，空 = 不限），上传前按
  「已用 + 本次大小」预检，装不下就跳下一个桶。用量按 `Media.size` 反解桶求和（见 `storage/bucket-usage.ts`）。
- 为什么不用另两种口径：ListObjectsV2 是 Class A 计费请求 + 大桶要翻页，塞进上传路径等于加钱加延迟；
  增量记账表在外部删对象后会单向漂移、无自愈路径。全量重算天然自愈，代价是漏掉缩略图字节（近似值）。
- 性能护栏：`s3HasCapacityLimit()` 为假时**一次库都不查**（`page.tsx` 与 `put` 都用它做闸门），
  所以「不配置 = 与升级前零差别」；配了则走 60s 进程内快照 + 并发去重 + 写后乐观累加。
- 三个切换触发点（记在 s3.ts 文件头）：人工 `full` 标记 → 容量预检 → 写入抛错。只有最后一个是
  服务商告诉我们的。
- **踩坑（值得记）**：容量上限**不能在 sanitize 里做合法性收敛**。最初写成 `normGb()` 把非法值清成 `""`，
  结果 `runtimeConfigIssues` 拿到的永远是清洗后的值 → 两条校验断言恒为 false（探针逮到）。
  更严重的是语义：静默降级成「不限」会让用户以为有防线而实际没有。改为 sanitize 只 trim + 截长、
  由 `isInvalidGb()` 在**保存时**报错拦下。
- 边界口径：判据是 `used + incoming > cap` 才跳（**正好填满允许**）；`startsWith: "http"` 过滤掉
  云盘（`/od/`）与本地（`/uploads/`）的 Media —— 它们不在 S3 桶里，收进来会白占主桶额度。
- 验证：tsc + eslint 干净；探针 37（配置层）+ 28（驱动层）+ 18（UI SSR 契约）全绿，含 2 组反证
  （预检恒不触发 → 8 条变红；type 导入改值导入 → 泄漏扫描变红）；客户端包扫描 125 入口 / 201 可达文件 PASS。
