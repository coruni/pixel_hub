## 本机 git 的坑（务必记住）
- **`git reset --hard` / 大范围 `git revert` / `git restore --staged --worktree` 之后，
  成百上千个 tracked 文件会从磁盘消失**（`git status` 显示满屏 ` D`，实际文件不在了）。
  已复现三次：reset --hard 后 `src/` 只剩 1 个条目；revert --no-commit 后同样；restore 后 `prisma/` 全没了。
- 补救：`git checkout -- .`（索引内容还在，无损恢复），然后**必须复核文件数**再继续操作。
- 所以本机做回滚，**别用 reset --hard 直接了事**；用 `git revert --no-commit <range>` + checkout + commit 更可控，
  也保留历史、能普通 push。

## 回滚范围内的技术结论（若将来重做可参考）
- **Next 16 的 cacheHandler 契约**（与 14 不同，写自定义后端必看）：
  - `set(key, data, ctx)`：data 是 **value 本体**（`{kind,…}`），不能摊平存；`data === null` = 删键。
  - `get()` 必须返回 `{ value, lastModified }`，返回 value 本体 → InvariantError E653
    `Expected cached value … to be a "FETCH" kind, got undefined instead.`
  - `ctx.softTags` 也要进标签索引：revalidatePath 走软标签（`_N_T_` 前缀），只索引 tags 会让它在自定义后端下失效。
  - Redis 过期交给写入时的 EX，别再按 revalidate 判一次（会把 SWR 的 stale 命中判成未命中）。
- **路径**：Next 两处解析 cacheHandler，基准不同 —— 构建期用 `dir`、运行时用 `distDir(.next)`，
  相对路径会让运行时去找 `/app/.next/cache-handler.js`；用 `path.join(process.cwd(), "cache-handler.js")`；
  Docker 运行阶段必须单独 COPY 该文件（不在 .next 里）。
- **凭据**：`@redis/client` 的 parseOptions 是 `Object.assign(options, parsedUrl)`，URL 内凭据会覆盖显式
  password；要先把 userinfo 从 URL 摘出再走 username/password 选项。
- **现成库**：`@neshca/cache-handler` latest 1.9.0 peer 要求 `next >= 13.5.1 < 15`，本项目 Next 16.3.4 装不上；
  v2 未发布。`cache-manager` 不懂 Next ISR 契约，接上仍要自己写 handler。

## /upload 粘贴上传只能出一张 —— 已修（`src/lib/hooks/use-file-paste.ts`）
- 症状：Ctrl+V 粘多张图，只上传第一张（实际是抛错，一张都没成）。
- 根因：FileList 替身缺 `@@iterator`。宿主 FileList 只有 `length` + 数字索引，**没有** `Symbol.iterator`；
  `Object.create(FileList.prototype)` 出来的替身既不继承迭代器、又不是真数组 → `Array.from` 只探到 `length === 0`，
  **无论粘几张都返回长度 1 的 `[undefined]`**（`fl[0]` 落在原型索引访问器上仍是 undefined）。
  消费方 `Array.from(fl).slice(...)` 正好放行这个 `[undefined]`，上游 `!fl.length` 也拦不住 → FormData.append 抛 TypeError。
- 修法：抽出 `asFileList()`，显式挂 `Symbol.iterator`（生成器按 `this.length` / `this[i]` 取值）。
  不选 `new DataTransfer()` —— Safari 14 及更早有版本没有它。
- **`useFileDrop` 无需动**：它直接透传宿主 `dataTransfer.files`（是真 FileList），所以拖拽多张一直正常。
  只有「自己造 FileList」的路径会踩这个坑。
- 验证：12 组（粘 1/2/3/12 张 × 剩余额度 1/3/12）全过；`tsc --noEmit` + eslint 干净。
