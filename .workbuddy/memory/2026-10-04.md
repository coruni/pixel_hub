## 视频播放器：选集开关下移 + hover title + 控件不自动隐藏

改 `src/components/resource/detail/av-controls.tsx`（一个文件，未提交）。

- **选集（分P / 曲目）开关从画面右上角挪到底部控件行**，与 `av-embed.tsx`（嵌入页播放器）
  的位置对齐；右上角只剩字幕开关（`capReady &&` 单独渲染，去掉并排的 gap）。
- **列表面板改为从底部往上顶**：`absolute bottom-[6.5rem] right-3 w-56 max-w-[calc(100%-1.5rem)]`，
  限高用 `maxHeight: calc(100% - 7rem)`（百分比按视频框高算 —— 窄屏视频矮，不夹住会从画面上方溢出）。
  `6.5rem` ≈ 控件条实高（pt-8 32 + 进度条 20 + 控件行 36 + pb-1.5 6 ≈ 94px）+ 余量。
- **列表面板打开时收起两侧上一/下一浮层按钮**（`multi && !listOpen`）：窄屏视频就那么高，
  两个侧按钮会被底部面板压住。
- **横排宽度**：320px 下控件条本来就排满，加一个 50px 的开关必然溢出 →
  时间只在 ≥375px 显示 ` / 总长`（`max-[374px]:hidden`，与 Navbar 的 `max-[359px]:` 同一写法）。
  实测 320 下余量 ~12px（postcss 实编确认 `bottom-[6.5rem]` / `max-[374px]:` / `max-w-[calc(...)]` 均有产出）。
- **补 title**：控件行里所有纯图标按钮（播放/暂停、静音、倍速、循环、全屏、音频分支同样一套）
  都补了 `title`，与既有 `aria-label` 同文案；下载位（MetaDownloadButton iconOnly）本来就有。
- **修复控件不自动隐藏**：旧实现只在 `pointermove` 里补挂 `armHide`，漏两种情况 ——
  ① 关掉分P 列表那一刻没有新的 pointermove，而计时器早被清掉 → 控件从此不再淡出（主因）；
  ② 播放不是指针触发（媒体键、自动续播）时同样没人补挂。
  现在改成 **effect 由 `playing`/`listOpen` 驱动**（列表开着不挂计时），关闭列表的动作由
  `toggleList()` 顺手把计时补回去；`pointermove` 里非播放态只补显示、不挂计时。
- 坑：**`react-hooks/set-state-in-effect` 在本仓库是 error**（eslint-plugin-react-hooks 新版规则），
  effect 里不能同步 `setUiOn(...)` —— 时间/可见性的同步 setState 一律放事件处理函数里，
  effect 只允许 `setTimeout` 里异步 setState（`armHide` 那种）。
- 验证：`tsc --noEmit` + `eslint src/components/resource/detail` 均干净；未跑 build / dev。

## 追加：控件「全都放底部」（用户要求）

同一批文件，画面上的浮层按钮清空，所有控件集中到底部控件行。

- **删除**视频两侧的上一/下一浮层、右上角字幕开关浮层；上一/下一进左组，字幕开关进右组。
- 控件行改为 **两个容器 + `flex-wrap`**：左组＝上/下一 + 播放 + 时间，spacer，右组＝字幕/选集/音量(sm+)/倍速/循环/下载/全屏。
  窄屏放不下时右组整体折到第二行（右组内按钮都 `shrink-0`，min-content 撑住 → 整块换行，不会被拆散）。
  实测：≥640px 一行（音量组回归后总量 ~560 / 可用 1096）；<640px 两行（行 A ≤192、行 B ≤252）。
- **字幕叠层改挂底部控件区外层 + `bottom-full`**（原来写死 `bottom-14`）：控件行折两行时字幕自动让开；
  且它不在做 opacity 淡出的那层里，字幕不随控件消失。
- **列表面板**：`listOpen` 时控件条整条淡出（`uiOn && !listOpen`），面板自己铺开 ——
  窄屏 `inset-x-0 bottom-0 max-h-full`（手机竖屏视频才 180–220px 高，不给满就只看得到一行），
  宽屏 `sm:inset-x-auto sm:right-3 sm:w-72 sm:max-h-[70%]`。`AvTrackList` 新增可选 `header`
  （标题「分P 3/8」+ 收起按钮）—— 窄屏面板盖住控件条，必须留个明确出口。
- `AvTrackList` 结构改为外层 flex-col + `<ol>`（`flex-1 min-h-0 overflow-y-auto`），
  **去掉自带 inline `maxHeight: 45vh`**（inline 会压过宿主的响应式 class）；三个调用处各给限高 class。
  注意 `divide-y-2` 必须留在 `<ol>` 上（放外层会变成给 header/ol 之间画线）。
- postcss 实编确认：`max-h-full`、`max-h-[45vh]`、`sm:max-h-[70%]`、`sm:inset-x-auto`、`max-[374px]:hidden` 均有产出。
