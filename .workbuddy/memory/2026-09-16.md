## 账户设置 tab：不换行改横向滚动
- `SettingsTabs.tsx`：外层拆成「`border-b border-neutral-200` 框」+「`-mb-px flex scrollbar-none gap-1 overflow-x-auto` 滚动层」；按钮补 `shrink-0 whitespace-nowrap`，去掉 `flex-wrap`。
- 坑 1（下划线压线）：`-mb-px` 必须挂在**滚动容器**上而不是按钮上——滚动容器会把 overflow-y 一并算成 auto 并裁掉自己的溢出，挂在按钮上那 1px 会被裁掉。实测 `activeBottom − wrapBottom` 由 10 → 0（0 = 品牌下划线正好盖住 track 线）。
- 坑 2（隐藏滚动条）：不能用 Tailwind 中括号任意值。`globals.css` 里 `* { scrollbar-width: thin }` 是**无层规则**，Tailwind 工具类落在 `@layer utilities`，层叠层序中无层优先于分层 → 任意值写法静默失效（实测仍占 10px）。改为在 `globals.css` 追加无层 `.scrollbar-none`（含 `::-webkit-scrollbar { display: none }`）。
- 新增 `useEffect`：active 变化时对激活 tab 调 `scrollIntoView({ inline: "nearest", block: "nearest" })`，解决 `?tab=account` 深链时激活项落在滚动区外看不见；`block: nearest` 避免整页上下跳。
- 验收方式（无截图）：headless Edge + 临时 harness 量几何。320px → 容器 288 / 内容 346 → 可滚、rows=1；375px → 343/346 → 可滚；390px → 358/358 → 恰好一行放下、不滚。三档均 `scrollbarReservedPx=0`、`activeBottomMinusWrapBottom=0`、`tabHeight=38`。
- 临时文件 `public/_tabcheck.html`、edge profile、抓下来的 css/html 已全部删除，未进工作区。
- 遗留：后台 `admin/SubTabs.tsx` 与 `SiteLayoutManager` 的 AREA_TABS 仍是 `flex-wrap`，窄屏同样会换行，本次未动（用户只点了账户设置）。
