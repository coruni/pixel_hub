# 2026-10-01 工作记录

## 图片上传前端预压缩（优化 10MB+ 原图）
- 新增 `src/lib/media/client-compress.ts`：`compressImageForUpload` / `compressImagesForUpload`。
  - 浏览器内 `createImageBitmap`+canvas 重编码，优先 webp（保透明，契合像素风 PNG），老浏览器退回 png/jpeg；最长边 >4096 降到 4096 内。
  - ≤200KB 不压；gif 不压（丢动画）；解不出或没压小降级用原文件。
  - 压图前先对**原始 File 字节**取 sha256（`crypto.subtle.digest`）作为去重指纹，随上传提交。
- 服务端去重指纹改为「客户端优先」：`/api/upload/route.ts` 与 `actions/social.ts` 的 `saveCommentImage` 收到合法 64-hex `checksums` 字段就用它，否则回退 `sha256Hex(收到字节)`；`checksum.ts` 新增 `isSha256Hex`。跨版本去重不失效。
- 三个调用点接入：`upload-image-client.ts` 的 `postOnce`、`MdEditor.tsx` 的 `onUpload`、`Comments.tsx` 的 `post`（主楼附图，并行 append `images`+`checksums`）。
- 验证：`tsc --noEmit` 与 `eslint`（仅 touched 文件）干净；tsc 其余报错为预存的 rootId/pinnedAt/category/profileBg* 等 schema 漂移（第三批迁移未上线），与本次无关。未跑 build/dev。
