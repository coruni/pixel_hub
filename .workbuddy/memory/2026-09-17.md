## 附件上传改为拖拽/点击投放区 + 上传与抽屉解耦 + 提交闸门
- 用户要求四点：① 允许拖拽/点击区域上传；② 拖拽后显示抽屉填信息；③ 关掉抽屉后仍可继续上传直到完成；④ 有上传任务时禁止提交。
- `AttachmentUpload.tsx` 新增 `variant="dropzone"`：整块虚线投放区（`UploadCloud` 20px + 主文案 + 规格提示），与 `variant="button"` 共用同一套状态；`dropProps`/`dragging` 由调用方展开。隐藏 input 抽成局部变量，点击与拖放共用。
- `AttachmentListEditor` 重构：
  - 外部主入口改为 dropzone；`useFileDrop({ onFiles, disabled: rows.length >= 20 })`。
  - **onFiles 不再依赖抽屉**：拖入即上传，逐个 `postAttachment` → 成功即 `setRows` 追加一行 → `if (!drawerHeldRef.current) setDraft(row)` 自动开抽屉。
  - **`disabled` 只挂钩清单满，不挂钩 busy**（原以为该挂 busy，实际那样会禁止「上传中继续拖入」，与需求③冲突）。
  - 进度改为 `doneRef`/`totalRef` 累计（并发批次不能互相冲掉）；`inflight` 驱动外部禁用。
  - 新增 `onBusyChange` 回调把在飞数交给宿主；`drawerHeldRef` 用 `useEffect` 维护（async 回调读 state 会拿到旧值）。
  - 抽屉内 file 分支改为「文件回显 + 更换文件」，未选文件时显示虚线占位并提示可去下方投放区上传。
- `UploadWizard.tsx` / `ResourceEditForm.tsx`：新增 `attachBusy` state，三个 Section 传 `onBusyChange={setAttachBusy}`；提交按钮 `disabled` 增加 `attachBusy > 0`，文案变「等待附件上传…」，旁边显示琥珀色提示；`<form onSubmit>` 里 `preventDefault()` 兜住回车提交。
- 验证：`tsc --noEmit` exit 0；eslint（upload 目录 + version.tsx + ResourceEditForm.tsx）exit 0。
