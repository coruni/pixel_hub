# 2026-09-29

## 修复：批量图片上传顺序混乱（自然排序）
- 现象：拖拽 / 选择多张图片批量上传时，图集 / 封面顺序乱掉。
- 根因：`dataTransfer.files`（FileList）的顺序浏览器不保证与文件管理器一致，甚至相反；`uploadImageFiles` 原样保留该混沌顺序。
- 改动：
  - 新增 `src/lib/natural-sort.ts`：`naturalCompare` + `sortFilesByNameNaturally`（按文件名自然序，img1<img2<…<img10，而非字典序 img1<img10<img2）。
  - `src/lib/upload-image-client.ts` 的 `uploadImageFiles` 在切批前先 `sortFilesByNameNaturally(files)`，再靠既有绝对下标回填，good 顺序稳定可预期；进度名也同步为排序后文件名。
- 影响面：发布向导 `UploadWizard.onFiles` 与后台改稿 `ResourceEditForm.onFiles` 两条图集/封面入口共用同一 chokepoint，一并修复；单帧 `[frame]` 调用为排序单元素，无副作用。评论附图走独立链路，未改动。
- 验证：`npx tsc --noEmit` 仅余仓库既有 Prisma client 与 schema 不同步错误（pinnedAt/featuredAt/nameColor/profileBgMobileKey/rootId 等），本改动零新增错误；`eslint` 两个文件通过。
