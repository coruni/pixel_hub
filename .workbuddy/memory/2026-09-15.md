
## 移动端 Navbar 挤压修复 + favicon 修复
- Navbar（src/components/layout/Navbar.tsx）：窄屏容器 gap-2/sm:gap-6、logo min-w-0+truncate+shrink-0、右侧操作区 shrink-0+gap-2/sm:gap-3、登录/注册 whitespace-nowrap、注册 px-3 sm:px-4、logo 字号 text-base sm:text-lg + max-[359px]:text-sm。用户已自行提交主体（45ff1ca），工作区剩 max-[359px] 兜底 1 行。实测 320/375/390/430/768 无溢出、无折行、按钮不压扁（Edge headless + CDP 截图验证）。
- favicon「不显示」根因：① icon.svg 外圈深棕 #1b150f 在深色标签栏上轮廓隐形（从 Chromium favicon 库导出的 16px 位图证实）；② /favicon.ico 404；③ 无 apple-touch-icon。修复：icon.svg 加 1px 金色 #e8a33d 外描边（内容变化→Next hash 变→缓存自动失效）；新增 src/app/favicon.ico（16/32/48 PNG-in-ICO，sharp 栅格化）与 src/app/apple-icon.png（180x180）。Chromium 接受性已通过读取 profile 的 Favicons SQLite 库验证。
- 复用工具：.workbuddy/tmp/cdp-shot.mjs（截图+布局诊断）、cdp-favicon.mjs（favicon 网络诊断）、cdp-favicon-db.mjs（favicon 落库验证）、gen-favicons.mjs（ico/apple-icon 生成）。临时脚本不提交。
- 注意：bash shim PATH 损坏，命令前需 export PATH="/usr/bin:/bin:$PATH"；curl 本机需 --noproxy '*'；本机 DB enum 缺 VIDEO 导致 / 500（既有环境问题，未动）。
