- 顺带定位到**第二个独立的 404 bug**：Next 16 页面 params **不解码**（route handler 才解）。用 `zz-param-probe/[slug]/route.ts` vs `zz-page-probe/[slug]/page.tsx` 对比实证：同一 URL 下 route 收解码态、page 收编码态。新增 `decodeSlug()`，接 3 个 slug 页面 ×（page + generateMetadata）。
